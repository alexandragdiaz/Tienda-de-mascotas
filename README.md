# 🐾 PetStore Ecommerce

Proyecto frontend responsive de una tienda para mascotas desarrollado con HTML, CSS y JavaScript.

---

# 📌 Características

✅ Diseño responsive  
✅ Navbar moderna y sticky  
✅ Hero section atractiva  
✅ Cards de productos dinámicas  
✅ Carrito lateral interactivo  
✅ Contador dinámico de productos  
✅ Eliminación de productos del carrito  
✅ Footer profesional  
✅ Paleta de colores moderna  
✅ UI/UX mejorada

---

# 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
